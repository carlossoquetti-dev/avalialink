Como usar

Cole o link do Google Maps e tente identificar o Place ID. Se não for possível, encontre o Place ID manualmente e clique em gerar. Compartilhe o link por WhatsApp ou use o QR Code em balcões, cartões, embalagens e etiquetas NFC.

O link com Place ID usa um formato conhecido de avaliação do Google, mas não é uma API oficial garantida. Confirme que ele abre a empresa certa. Para empresas que você administra, também é possível obter o link oficial no Perfil da Empresa no Google.
