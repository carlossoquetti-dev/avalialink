1. Encontrar estabelecimento

Pesquise gratuitamente no Google Maps e confira qual empresa é a correta. A pesquisa abre em outra aba; o Google Maps não envia automaticamente o Place ID ao AvaliaLink.

Localizar Place ID no Google ↗

Depois de identificar a empresa, use o link oficial de avaliação ou um Place ID obtido por uma fonte confiável. Não cole o link comum do Maps no campo de avaliação.

2. Dados da empresa

Peça ao responsável pelo Perfil da Empresa no Google o link para solicitar avaliações. Links comuns de localização do Maps não são links de avaliação.

Abrir Google Maps ↗

3. Conferir link antes de gravar

Testar avaliação ↗

Antes de vender: abra o link, confira o nome da empresa e se aparece a tela para escrever uma avaliação. O gerador não consegue verificar isso automaticamente.

4. QR Code para impressão

Use o mesmo endereço no QR Code e no NFC Tools. Teste ambos com um celular antes de entregar.

5. Clientes salvos neste navegador

Os dados ficam apenas neste navegador, sem conta ou servidor. Limpar os dados do navegador pode apagá-los.

Como gravar a NTAG213

No Android: NFC Tools → Escrever → Adicionar registro → URL/URI → cole o link → OK → Escrever. Aproxime a tag e aguarde a confirmação. Não bloqueie a tag permanentemente antes de testar.

NTAG213: 144 bytes de memória NDEF. O indicador de tamanho abaixo é uma estimativa para um único registro URI; o aplicativo pode usar bytes adicionais. Confirme o espaço e a gravação no NFC Tools.

AvaliaLink é independente e não é afiliado ao Google. Não incentive apenas avaliações positivas nem ofereça recompensas por avaliações.
