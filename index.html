Como usar

Cole o link completo do Google Maps, clique em Identificar estabelecimento e depois em gerar. Se o endereço não tiver identificador compatível, use o Place ID. Compartilhe o link por WhatsApp ou use o QR Code em balcões, cartões, embalagens e etiquetas NFC.

O link com Place ID usa um formato conhecido de avaliação do Google, mas não é uma API oficial garantida. Confirme que ele abre a empresa certa. Para empresas que você administra, também é possível obter o link oficial no Perfil da Empresa no Google.
